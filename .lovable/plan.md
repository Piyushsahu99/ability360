# More accessibility features

## What will be added

- Expand the floating accessibility menu with **text spacing**, **comfortable line height**, **larger cursor**, **strong focus highlights**, and **hide decorative images**.
- Add a **reading guide** that follows the pointer to help users track lines of text.
- Add a visible **Skip to main content** link for keyboard and screen-reader users.
- Keep every display choice saved on the current device, available before sign-in, and compatible with the existing reset control.

## Accessibility details

- New controls use labelled switches with 44px touch targets.
- The reading guide will ignore clicks and disappear when disabled.
- Existing high contrast, reduced motion, readable font, link underlining, and text sizing remain unchanged.
- Decorative imagery hiding will preserve meaningful content images and their alternative text.

## Verification

- Test all controls, reset, keyboard navigation, mobile layout, persistence after reload, and reduced-motion behaviour.
- Confirm the app builds cleanly and no new browser errors appear.
