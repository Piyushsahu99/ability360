# Ability 360

Build the foundation of ABILITY360, a personalised Academia–Industry Career OS for college students.



Tagline: “From First Semester to First Career.”



The platform connects Students, Colleges, Faculty, Industry and Opportunities.



Use:

- React + TypeScript

- TanStack Start if supported

- Tailwind CSS

- shadcn/ui

- Lucide icons

- PostgreSQL

- TanStack Query

- Zod



Create a modern, professional and accessibility-first design.



Do NOT build advanced features yet.



Create:

- Landing page

- Login

- Register

- Student dashboard shell

- Industry dashboard shell

- Institution dashboard shell

- Admin dashboard shell

- Opportunities page



Use clean white/off-white surfaces, navy primary colour, accessible accent colours and minimal animations.



Make the UI responsive and mobile friendly.


**Live app**: https://ability360.lovable.app
